Referencia API

Integre los datos de ElCafé Capital en sus propias aplicaciones.

Autenticación

Todas las solicitudes a la API (excepto la verificación de estado) requieren que se envíe una clave API en la cabecera Authorization: Bearer YOUR_API_KEY. Puede generar su clave en el Portal API.

curl -H "Authorization: Bearer YOUR_API_KEY" https://api.elcafecapital.com/v1/...

Endpoints de Simulación

POST /v1/simulate

Ejecute una simulación de Monte Carlo estándar utilizando los motores Hermes o Kronos.

Cuerpo de la Solicitud (SimulateRequest):

{
  "ticker": "cadena",
  "n_sim": "entero [1000, 5000000]",
  "sim_days": "entero [1, 252]",
  "min_window": "entero [2, 252]",
  "engine": "cadena ^(auto|hermes|kronos)$",
  "seed": "entero (opcional)"
}

POST /v1/simulate/afrodita

Ejecute una simulación especializada de volatilidad estocástica de Afrodita.

Cuerpo de la Solicitud (AfroditaRequest):

{
  "ticker": "cadena",
  "n_paths": "entero [100, 100000]",
  "window": "entero [1, 60]",
  "seed": "entero (opcional)",
  "use_hermes_closes": "booleano (opcional)",
  "n_hermes": "entero (opcional)"
}

Endpoints del Sistema

GET /v1/health

Compruebe el estado de salud de la API (No requiere autenticación).

GET /v1/calibrate

Calibrar modelos del sistema.
